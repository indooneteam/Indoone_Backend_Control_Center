# Indoone Control Center — Login page

The standalone static login UI is located at `web/login/index.html`.

## Preview

Open `index.html` directly in a browser, or serve the repository root with any static file server and visit `/web/login/`.

## Security status

This page is currently a UI preview only. The sign-in form does not transmit or save email/password values and does not authenticate accounts. Connect server-side authentication, secure sessions, and role-based permissions before enabling real sign-in.

Do not add passwords, API keys, or production secrets to this folder.
